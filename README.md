# Streetloop

Streetloop is a working title for an original third-person city sandbox by Chaosmos Studio.
The project begins with one playable harbor block and grows through separately built districts, vehicles, characters, and city systems.

The first milestone is a place to walk, drive, and interact in, with art made for the actual game camera.
The game uses Godot 4.7 and Blender 5.2.

Read [PLAN.md](PLAN.md), [ART_DIRECTION.md](ART_DIRECTION.md), and [ASSET_CATALOG.md](ASSET_CATALOG.md) before adding assets or systems.
